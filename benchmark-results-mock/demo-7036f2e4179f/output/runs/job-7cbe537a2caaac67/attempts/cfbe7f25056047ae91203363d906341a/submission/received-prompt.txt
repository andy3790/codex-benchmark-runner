# 개발 과제: 숫자 분석 JSON CLI

Python 3.12 표준 라이브러리만 사용하여 `solution.py`를 구현하세요.

프로그램은 표준 입력에서 JSON 객체 하나를 읽고 표준 출력에 JSON 객체 하나만 출력합니다.
입력 형식은 `{"numbers": [정수, ...]}`입니다. 각 정수는 절댓값 1,000,000,000 이하이고,
배열 길이는 0 이상 100,000 이하입니다. bool은 정수로 취급하지 않습니다.

정상 입력에 대한 출력은 `sorted`(오름차순 배열), `sum`(정확한 정수 합),
`median`(중앙값, 짝수 길이면 가운데 두 값의 평균, 빈 배열이면 null) 필드를 갖습니다.
추가 필드는 넣지 마세요. JSON 파싱 실패, 필수 키 누락, 잘못된 타입/범위는
`{"error": "invalid_input"}`을 출력하고 종료 코드 0으로 종료하세요. 추가 입력 키는 무시합니다.

100,000개 정수 입력을 단일 CPU에서 5초 이내 처리할 수 있는 알고리즘을 사용하세요.
네트워크 또는 외부 패키지는 사용하지 마세요. 필요하면 자체 테스트와 사용 설명을 작성하세요.
현재 작업 폴더 안에서만 작업하며 다른 실험이나 채점 파일을 탐색하지 마세요.
